# 代码改动同步清单

每次改动代码后，按以下清单检查是否需要同步更新对应文件。

## 一、必定检查

| 文件 | 触发条件 |
|------|----------|
| [README.md](../README.md) | 新增/删除功能模块 → 更新"## 功能" |
| | 文件增删/路径变更 → 更新"## 目录结构" |
| | 框架/库变更 → 更新"## 技术栈" |
| | config.yaml 新字段 → 更新"## 配置" |
| | .env.example 新变量 → 更新"## 环境变量" 表格 |
| | 行为变化（登录、密码等）→ 更新"## 常见问题" |

## 二、依赖

| 文件 | 触发条件 |
|------|----------|
| [requirements.txt](../requirements.txt) | 新增 import 第三方包 → 必须显式声明（装了不算，要写上） |

## 三、配置

| 文件 | 触发条件 |
|------|----------|
| [config.yaml](../config.yaml) | 新增/修改配置项 |
| [.env.example](../.env.example) | 新增环境变量 → 同时更新 README 环境变量表 |

## 四、启动 & 部署

| 文件 | 触发条件 |
|------|----------|
| [scripts/启动.bat](../scripts/启动.bat) | 启动流程变化 |
| [Dockerfile](../Dockerfile) | 启动命令、环境变量、版本号 |
| [docker-compose.yml](../docker-compose.yml) | 环境变量、端口、挂载路径 |
| [.dockerignore](../.dockerignore) | 废弃目录/文件类型清理 |

## 五、文档（每次必须）

| 文件 | 触发条件 |
|------|----------|
| [docs/交接文档.txt](交接文档.txt) | 版本号、文件结构、当前环境、待补完状态 |
| [docs/维护日志.txt](维护日志.txt) | **每次改动后追加操作记录** |

## 六、UI

| 文件 | 触发条件 |
|------|----------|
| [ui/server.py](../ui/server.py) | API 端点、版本号、全局状态 |
| [ui/templates/index.html](../ui/templates/index.html) | 页面结构、导航按钮、页面内容 |
| [ui/static/style.css](../ui/static/style.css) | 样式变更 |
