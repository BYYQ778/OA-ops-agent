OA运维智能Agent巡检系统 - 离线部署包
========================================
版本: v2.0 MVP
日期: 2026-05-18

使用方法（完全离线，0 联网）
----------------------------------------
1. 把整个文件夹拷贝到目标 Windows 服务器
2. 双击 oa-ops-agent\启动.bat
3. 浏览器自动打开 http://127.0.0.1:7860

首次启动会自动:
  ✓ 安装 Ollama（离线）
  ✓ 导入本地 AI 模型（如已准备 ollama-models）
  ✓ 安装 Python 依赖（从 offline/wheels 离线安装）
  ✓ 启动 OA 运维巡检系统

如缺少本地模型:
  - 方式1: 在有网机器运行 ollama pull qwen2.5:7b
           然后拷贝 C:\Users\<用户名>\.ollama 到 ollama-models\
  - 方式2: 修改 config.yaml → llm.provider: deepseek 使用云端 AI

包内容
----------------------------------------
oa-ops-agent/        项目代码 + Python 虚拟环境 (含全部依赖)
offline/             离线资源
  wheels/            Python 依赖包
ollama-models/       本地 AI 模型（需自行准备）

快捷方式
----------------------------------------
启动.bat             一键启动（推荐）
下载离线依赖.bat     在有网环境补全依赖包
