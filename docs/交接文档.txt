一、项目概述
═══════════════════════════════════════════════════════════

OA运维多智能Agent巡检问答系统，面向运维实习生的智能运维辅助平台。
基于 Python + LangChain + RAG + Chroma 构建。

核心模块:
  实时监控仪表盘 → SSE推送 + 5状态卡片 + Chart.js趋势图 + 告警时间线 + 日志控制台
  巡检Agent → 端口/Nginx/OA服务/磁盘/内存 五项检测
  日志分析Agent → 10+正则规则自动识别故障
  知识库Agent → RAG 智能问答 + 场景自动推荐匹配命令
  诊断工具箱 → SSL证书 / 网络诊断 / 数据库巡检(MySQL+MSSQL+Oracle+Redis) / 安全基线
  OCR识别 → 知识库图片导入 / 日志截图识别（CnOCR + hf-mirror国内直连）
  本机巡检 → Windows 原生命令真实数据采集
  AI 报告 → 巡检后自动生成预警分析 + 改进策略
  运维命令大全 → 136条命令/6大分类/双向搜索/卡片展开/关键词高亮
