## 三、架构与关键文件

```
GUI 主进程（desktop_app.py 主分支）          后端子进程（desktop_app.py --backend）
  ├─ PyWebView (Edge WebView2) 窗口            └─ uvicorn + FastAPI (ui/server.py)
  ├─ 启动画面轮询 /api/health                    └─ 全部 AI 依赖（langchain/chromadb/torch/OCR）
  └─ 关窗 → terminate 后端子进程
```

**进程隔离原因**：WebView2(Chromium) 与 torch/onnxruntime 同进程并发加载会原生崩溃（0xc0000409），必须拆成两个进程。

关键文件：

| desktop_app.py | 桌面壳主入口（源码/打包双模式；`--backend` 子进程跑后端） |
| oa_agent.spec | PyInstaller 构建配方（已提交；.gitignore 的 `*.spec` 已用 `git add -f` 强制入库） |
| scripts/打包绿色版.bat | 一键重新打包 |
| scripts/启动桌面版.bat | 源码模式启动入口 |

## 四、踩过的坑（重要，防止重踩）

1. **PyInstaller excludes 不能含 unittest**：torch/sklearn/numpy 顶层 `import unittest`，排除会导致冻结版启动原生崩溃 0xc0000409（事件日志见 ucrtbase.dll）。已从 spec 移除。
2. **chromadb 必须 collect_all**：动态导入 `chromadb.telemetry.product.posthog` 等；漏了会报 `No module named 'chromadb.telemetry.product.posthog'` → 知识库引擎"未就绪"。
3. **cnocr/cnstd/rapidocr 需 collect_data + collect_submodules**：自带 yaml/onnx/字典（rapidocr onnx 模型约 15MB），不收集则 OCR 导入链失败。
4. **进程隔离**：GUI 与后端必须拆进程（见第三节）。
5. **窗口图标**：WM_SETICON 在窗口显示后设置对任务栏不生效；必须在 `BrowserForm.__init__` 里设 `Form.Icon`（monkey-patch `winforms.BrowserView.BrowserForm`）。
6. **桌面壳健康检查**：urllib 探测 localhost 会被系统代理干扰 → 用 `ProxyHandler({})` 绕过；端口被占时先等最多 20s 确认是否本系统服务再复用，避免误判。
7. **前端离线**：原 Chart.js/vis-network 走 CDN、Google Fonts render-blocking → 下载到 ui/static/vendor/ 并移除字体链接。
8. **config.yaml 第 81 行 yaml 怪癖**：`ssl_monitor.domains` 的 flow sequence 带行内注释导致 PyYAML safe_load 失败（应用内 utils/config.py 能处理）；desktop_app 读端口用 yaml + 正则双兜底。
9. **旧坑回顾**：config.yaml 明文 API Key 曾因"LLM 热切换"写回 → 已回退为 `${OA_LLM_API_KEY:}`（.env 注入），且历史已重写清除密钥。

## 六、使用说明（给用户/同事）

- 双击桌面「OA运维Agent」或 dist 里的 exe 即可启动。
- 首次运行自动生成 config.yaml / .env.example → 配置 `.env`（填 OA_LLM_API_KEY）或改 config.yaml 用 Ollama。
- 数据（知识库/对话/巡检/日志）在 exe 同目录 `data/`。
- 排错看 `data/desktop.log`（桌面壳）、`data/backend.log`（后端）。
- 整个 `OA运维Agent` 文件夹可整体拷贝分发（免装 Python/Ollama）。
